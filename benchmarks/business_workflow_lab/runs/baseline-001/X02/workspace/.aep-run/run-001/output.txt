# Lab ERP（模擬 SAP 類查詢網頁）使用說明

> 合成測試資料。介面只是類似企業查詢系統的模擬，不是真實 SAP。

- 網址：http://127.0.0.1:8810/
- 測試帳號：`lab.analyst`，密碼：`Lab#2026`（僅限本機測試）
- 登入頁：`http://127.0.0.1:8810/login`，欄位 User（`#username`）、Password（`#password`），按 **Sign in**。
- 登出：右上角 **Log out**。

## 查詢頁

上方選單有 **Customers**、**Sales Orders**、**Invoices** 三個查詢頁。

篩選欄位（輸入後按 **Search**）：

| 欄位 | 說明 |
|---|---|
| Customer ID | 客戶代碼，完全相符，例如 C001 |
| Project | 專案代碼，完全相符，例如 P001 |
| Date from / Date to | YYYY-MM-DD，含起訖兩日；Sales Orders 用 OrderDate，Invoices 用 InvoiceDate |
| Status | 只在 Sales Orders：Open、Closed、Cancelled |
| Sort by / Order | 排序欄位與 asc / desc |

- 每頁 10 筆，頁面顯示 `Total: N rows · Page x of y`；用 **Next ›** / **‹ Previous** 換頁。
- 沒有符合資料時顯示「查無資料（0 筆）」。
- 點文件編號（OrderID / InvoiceID）進入 detail 頁。訂單 detail 有列表沒有的欄位：
  **CustomerContact**、**PaymentTerms**、SalesRep，以及 Line items（LineNo、ProductID、Quantity、UnitPrice、LineAmount）。
- **Export CSV (all filtered rows)** 會下載目前篩選條件的全部結果（不只目前這一頁），UTF-8 CSV。
- 列表欄位：
  - Sales Orders：OrderID、CustomerID、CustomerName、ProjectID、OrderDate、Status、Currency、NetAmount
  - Invoices：InvoiceID、OrderID、CustomerID、ProjectID、InvoiceDate、DueDate、Currency、Amount、PaidAmount、Balance（Balance = Amount − PaidAmount）
- 文件編號有前導零（例如 0045000101），請當成文字處理。
- 工作階段可能逾時：此時會回到登入頁並顯示「工作階段已逾時，請重新登入」，重新登入後即可繼續。
- 金額為原幣；不同幣別不可直接相加。

# Expense Viewer（模擬原生桌面費用程式）使用說明

> 合成測試資料。這是 Windows 桌面視窗程式（Tkinter），不是網頁。

- 啟動：`python "C:\Users\Chi_L\Documents\ChatGPT\agentic-engineering-platform\benchmarks\business_workflow_lab\expense_desktop_mock\expense_app.py"`（需要已登入的互動式 Windows 桌面）
- 視窗標題：`Expense Viewer (synthetic lab)`

## 主視窗

| 控制項 | 說明 |
|---|---|
| Employee 員工 | 下拉選單 E001～E006，空白代表全部 |
| Project 專案 | 下拉選單 P001～P005，空白代表全部 |
| Date from 起 / Date to 迄 | YYYY-MM-DD，含起訖兩日（ExpenseDate） |
| Status 狀態 | Draft、Submitted、Approved、Rejected，空白代表全部 |
| Query 查詢 | 執行查詢，完成後跳出「查詢完成，共 N 筆」或「查無資料（0 筆）」 |

- 結果表格每頁 8 筆，下方顯示 `Total N rows · Page x / y`，用 **Previous 上一頁** / **Next 下一頁** 換頁。
- 表格欄位：ExpenseID、EmployeeID、EmployeeName、ProjectID、ExpenseDate、Category、Currency、Amount、Status。
- 選一列後按 **Details 明細**（或雙擊該列）開啟明細視窗，內含 ReceiptID、Category、Description（可能含中文與換行）、MissingReceipt；按 **Close 返回** 關閉。
- **Export CSV 匯出 CSV**、**Export Excel 匯出 Excel**：開啟 Windows「另存新檔」對話框，匯出目前篩選條件的全部結果（不只目前這一頁），欄位包含 ReceiptID、Description、MissingReceipt。
- 匯出若顯示「暫時無法寫入，請重試」，表示這次沒有產生檔案，可以再按一次匯出。
- 程式沒有其他資料介面；請透過視窗操作與匯出取得資料。

# quote_cli（模擬報價系統 CLI）使用說明

> 合成測試資料。

- Windows 執行：`"C:\Users\Chi_L\Documents\ChatGPT\agentic-engineering-platform\benchmarks\business_workflow_lab\quote_cli_mock\quote_cli.cmd" <command>`
- 跨平台執行：`python "C:\Users\Chi_L\Documents\ChatGPT\agentic-engineering-platform\benchmarks\business_workflow_lab\quote_cli_mock\run_quote_cli.py" <command>`
- `quote_cli --help` 的內容如下：

```text
usage: quote_cli [-h] {customers,quotes} ...

quote_cli: the synthetic quote system's public command line.

Contract (stable, schema_version 1):
  quote_cli --help
  quote_cli customers list --format json
  quote_cli quotes list [--customer C001] [--project P001] [--from YYYY-MM-DD]
                        [--to YYYY-MM-DD] [--status Draft|Sent|Accepted|Expired]
                        [--format json|table]
  quote_cli quotes get Q0001 [--format json|table]
  quote_cli quotes export [filters as list] --output quotes.csv

Every filter is optional and filters combine with AND; dates include both
ends. stdout carries only the result (JSON or table); errors and diagnostics
go to stderr. Money is a decimal string in JSON ("1234.50"): parse it with a
decimal type, not a float. Nothing here creates or changes a quote.

Exit codes: 0 success (zero rows included), 2 invalid arguments, 3 document
not found, 4 temporary service error (retry later).

positional arguments:
  {customers,quotes}
    customers         customer master data
    quotes            quotes

options:
  -h, --help          show this help message and exit
```

補充：
- `quotes list` 回傳 `{"schema_version": 1, "items": [...], "count": N}`；`items` 只有表頭欄位。
- `quotes get Q0001 --format json` 回傳 `{"schema_version": 1, "header": {...}, "line_items": [...]}`，line items 欄位：ProductID、ProductName、Quantity、UnitPrice、LineAmount。
- 表頭欄位：QuoteID、CustomerID、ProjectID、QuoteDate、ValidUntil、Status、Currency、Subtotal、DiscountPercent、NetAmount。
- NetAmount = Subtotal × (1 − DiscountPercent / 100)，四捨五入（ROUND_HALF_UP）至兩位小數；LineAmount = Quantity × UnitPrice。
- 只有 exit code 0 時 stdout 才是正式資料；錯誤訊息在 stderr。
