001: # quote_cli（模擬報價系統 CLI）使用說明
002: 
003: > 合成測試資料。
004: 
005: - Windows 執行：`"C:\Users\Chi_L\Documents\ChatGPT\agentic-engineering-platform\benchmarks\business_workflow_lab\quote_cli_mock\quote_cli.cmd" <command>`
006: - 跨平台執行：`python "C:\Users\Chi_L\Documents\ChatGPT\agentic-engineering-platform\benchmarks\business_workflow_lab\quote_cli_mock\run_quote_cli.py" <command>`
007: - `quote_cli --help` 的內容如下：
008: 
009: ```text
010: usage: quote_cli [-h] {customers,quotes} ...
011: 
012: quote_cli: the synthetic quote system's public command line.
013: 
014: Contract (stable, schema_version 1):
015:   quote_cli --help
016:   quote_cli customers list --format json
017:   quote_cli quotes list [--customer C001] [--project P001] [--from YYYY-MM-DD]
018:                         [--to YYYY-MM-DD] [--status Draft|Sent|Accepted|Expired]
019:                         [--format json|table]
020:   quote_cli quotes get Q0001 [--format json|table]
021:   quote_cli quotes export [filters as list] --output quotes.csv
022: 
023: Every filter is optional and filters combine with AND; dates include both
024: ends. stdout carries only the result (JSON or table); errors and diagnostics
025: go to stderr. Money is a decimal string in JSON ("1234.50"): parse it with a
026: decimal type, not a float. Nothing here creates or changes a quote.
027: 
028: Exit codes: 0 success (zero rows included), 2 invalid arguments, 3 document
029: not found, 4 temporary service error (retry later).
030: 
031: positional arguments:
032:   {customers,quotes}
033:     customers         customer master data
034:     quotes            quotes
035: 
036: options:
037:   -h, --help          show this help message and exit
038: ```
039: 
040: 補充：
041: - `quotes list` 回傳 `{"schema_version": 1, "items": [...], "count": N}`；`items` 只有表頭欄位。
042: - `quotes get Q0001 --format json` 回傳 `{"schema_version": 1, "header": {...}, "line_items": [...]}`，line items 欄位：ProductID、ProductName、Quantity、UnitPrice、LineAmount。
043: - 表頭欄位：QuoteID、CustomerID、ProjectID、QuoteDate、ValidUntil、Status、Currency、Subtotal、DiscountPercent、NetAmount。
044: - NetAmount = Subtotal × (1 − DiscountPercent / 100)，四捨五入（ROUND_HALF_UP）至兩位小數；LineAmount = Quantity × UnitPrice。
045: - 只有 exit code 0 時 stdout 才是正式資料；錯誤訊息在 stderr。
