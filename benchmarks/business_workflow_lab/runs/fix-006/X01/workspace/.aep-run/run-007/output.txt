# Expense Viewer（模擬原生桌面費用程式）使用說明

> 合成測試資料。這是 Windows 桌面視窗程式（WinForms），不是網頁。

- 在 AEP 中已登記為桌面應用程式 `expense`（由平台啟動，需要已登入的互動式 Windows 桌面）。
- 視窗標題：`Expense Viewer (synthetic lab)`
- 控制項名稱（UI Automation id）：EmployeeFilter、ProjectFilter、DateFrom、DateTo、StatusFilter、QueryButton、ResultsList、PreviousButton、NextButton、CountLabel、DetailsButton、ExportCsvButton、ExportExcelButton；明細視窗為 Detail<欄位>（例如 DetailReceiptID）與 CloseButton。

## 主視窗

| 控制項 | 說明 |
|---|---|
| Employee 員工 | 下拉選單 E001～E006，空白代表全部 |
| Project 專案 | 下拉選單 P001～P005，空白代表全部 |
| Date from 起 / Date to 迄 | YYYY-MM-DD，含起訖兩日（ExpenseDate） |
| Status 狀態 | Draft、Submitted、Approved、Rejected，空白代表全部 |
| Query 查詢 | 執行查詢，完成後跳出「查詢完成，共 N 筆」或「查無資料（0 筆）」 |

- 結果表格每頁 8 筆，下方顯示 `Total N rows · Page x / y`，用 **Previous 上一頁** / **Next 下一頁** 換頁。
- 表格欄位：ExpenseID、EmployeeID、EmployeeName、ProjectID、ExpenseDate、Category、Currency、Amount、Status。
- 選一列後按 **Details 明細**（或雙擊該列）開啟明細視窗，內含 ReceiptID、Category、Description（可能含中文與換行）、MissingReceipt；按 **Close 返回** 關閉。

# Lab ERP（模擬 SAP 類查詢網頁）使用說明

> 合成測試資料。介面只是類似企業查詢系統的模擬，不是真實 SAP。

- 網址：http://127.0.0.1:8810/
- 登入：公司帳號自動登入（SSO）。開啟網址後若出現登入頁，按 **使用公司帳號登入 Continue with company account** 即可，不需要輸入帳號或密碼。
- 登出：右上角 **Log out**。

## 查詢頁

上方選單有 **Customers**、**Sales Orders**、**Invoices** 三個查詢頁。

篩選欄位（輸入後按 **Search**）：

| 欄位 | 說明 |
|---|---|
| Customer ID | 客戶代碼，完全相符，例如 C001 |
| Project | 專案代碼，完全相符，例如 P001 |
| Date from / Date to | YYYY-MM-DD，含起訖兩日；Sales Orders 用 OrderDate，Invoices 用 InvoiceDate |
| Status | 只在 Sales Orders：Open、Closed、Cancelled |
| Sort by / Order | 排序欄位與 asc / desc |

- 每頁 10 筆，頁面顯示 `Total: N rows · Page x of y`；用 **Next ›** / **‹ Previous** 換頁。
- 沒有符合資料時顯示「查無資料（0 筆）」。
- 點文件編號（OrderID / InvoiceID）進入 detail 頁。訂單 detail 有列表沒有的欄位：
  **CustomerContact**、**PaymentTerms**、SalesRep，以及 Line items（LineNo、ProductID、Quantity、UnitPrice、LineAmount）。
- **Export CSV (all filtered rows)** 會下載目前篩選條件的全部結果（不只目前這一頁），UTF-8 CSV。
- 列表欄位：
  - Sales Orders：OrderID、CustomerID、CustomerName、ProjectID、OrderDate、Status、C
