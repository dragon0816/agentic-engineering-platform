# knowledge_v1 core-012：候選 C3（第一稿就逐行引用）

2026-10-12。建立在 C1 + C2（core-011）之上。這是本次三個候選中的最後一個。

## 改了什麼

只改 wiki-primary 合成的提示詞（`425c5f6`，`WIKI_CITATION_FORM`）：每一句、每一行列表或表格都要帶
`[n]`，包括開場句、「Short answer」句，以及「段落沒有說什麼」的句子（引用它所談的段落）；
小標用 Markdown 標題，不要用沒有引用的粗體行。Host 的檢查規則、重試次數與拒答方式都沒變。

原因：離線重播 8 題，有 7 題第一稿只因 1–3 行沒有引用的框架句（「… as follows:」、「Short answer: …」、
「The passages do not rank …」）而沒通過引用預檢，於是幾乎每題都要重新生成一份較短的新稿。
加上這段提示後，離線第一稿通過率 1/8 → 4/8。

## 解讀

1. 涵蓋率小幅再升（+0.011，在重評浮動之內，但方向一致），PASS 明顯增加，時間少 12%。
2. 一次合成就通過的題數 3 → 13，所以省下第二次生成的時間，最終答案也較常是完整的第一稿。
3. **invented 回升**（54 → 67）。第一稿比重寫稿長，引用了參考答案沒用到的段落事實或延伸。
   評審的 invented 判斷依賴參考答案的「vault 沒有」段落，有雜訊，但這仍是下一步要看的指標。

## 決定

涵蓋率高於基準與 C2，時間改善，PASS 增加，contradicted 大致持平，**保留 C3**。
退回方式：revert `425c5f6` 並重啟 Agent Web。
