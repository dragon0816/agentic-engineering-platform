# knowledge_v1 core-010：候選 C1（照原文提問 + 檢索加速）

2026-10-12。對照組：core-009（同日基準，HEAD `0be2b14`、Skill 1.10.0）。

## 改了什麼

1. **`engineering/knowledge-query@1.0.1`**（1.0.0 移到 `disabled/`）：只改 `instructions`。
   舊版寫「只能用 Raw 證據引用作答」，對話模型因此在問題後面加「請引用 Raw 證據」。
   新版要求把使用者的問題原文傳給 vault（追問時只補成完整句），不要加引用、證據類型、焦點、
   產品、排序或格式的指示，由 Knowledge Skill 決定檢索與引用。
2. **`VAULT_QUESTION_SCHEMA`**（`9d0d74c`）：tool 的 `question` 欄位說明改成同樣的要求，
   適用所有 vault。
3. **檢索加速**（`204dcfa`）：同一個 vault 的 RetrievalSnapshot 在檔案沒變之前重複使用
   （用一次 `scandir` 掃描的檔案數、最新修改時間與總大小判斷），大型 corpus 的 BM25 統計量也只算一次。
   離線驗證：22 題可回答題的檢索輸出與舊程式完全相同（22/22），檢索本身快約 10 倍。

驗證規則、拒答方式、Harness 階段與模型呼叫次數都沒有改。

## 結果

| | core-009（基準） | core-010（C1） |
|---|---|---|
| 可回答 22 題涵蓋率 | 0.372 | **0.423** |
| 可回答 22 題 PASS / 不足 / FAIL / 系統錯誤 | 15 / 2 / 4 / 1 | **17 / 0 / 5 / 0** |
| 證據不足 14 題涵蓋率 | 0.281 | 0.344 |
| 全部 36 題 PASS / 不足 / FAIL | 21 / 6 / 8（+1 系統錯誤） | **26 / 2 / 8** |
| 同上，評審可看全部引用段落時（見 core-011 檢討） | 21 / 6 / 8 | 28 / 2 / 6 |
| contradicted 合計（可回答） | 27（16） | **12（2）** |
| invented 合計（可回答） | 47（26） | 67（40） |
| 中位數 / p90 回應時間 | 185 / 329 s | **72 / 114 s** |

- tool 路徑的問題現在照原文傳遞（抽查前幾題全部 VERBATIM）。
- 先前「沒有 Raw 段落支持」而崩掉的題目恢復：Q0646 0.125 → 0.50、Q0871 0 → 0.31、Q1001 0.125 → 0.50。
  Q0296、Q0911 不再自相矛盾，但涵蓋率仍低，因為關鍵頁面（衛星酬載、OBC、RFIC 案例）沒被檢索到。
- 中位數時間少 61%：約 25 秒來自不再重建 corpus 與重算 BM25，其餘來自不再因錯誤提問而重試、
  失敗後由對話模型重答。
- **invented 增加**（47 → 67）。逐題看，多數是答案引用了參考答案沒用到的段落事實（例如 Q0846 的
  CMX-KS 選配代碼、Q1041 的 PCIe 眼圖數值），評審因參考答案的「vault 沒有」段落而標為 invented；
  也有一部分是真的延伸（Q0296 把 DO-160 測試需求寫成示波器機會）。崩掉的短答案原本不會有 invented，
  所以這個數字上升有一部分是答案變完整的代價。

## 決定

涵蓋率超過基準（0.372 → 0.423，且高於 core-005 的 0.395），中位數時間大幅改善，PASS 增加，
contradicted 大減，**保留 C1**。invented 是下一步要盯的指標。
