   只把 `evidence_sections` 從 64 改成 96，其餘相同（`evidence_chars` 仍是 80,000）。
   1.11.0 是先前退回的版本，所以跳號。

## 解讀

1. **涵蓋率再升 0.04，達到 0.466。** 離目標 0.50 和第二份 Claude Code 答案的 0.53–0.60 已經很近。
2. **run.py 的 PASS 下降是評審視窗造成的。** run.py 的評審只看答案引用的前 16 段、每段 1,500 字。
   C2 的答案引用更多段落：FAIL 題平均引用 17.1 段，11 題中有 7 題超過 16 段，評審看不到後面的段落，
   就判「有主張沒有依據」。用同一個評審、但讓它看到最多 48 段重評（不寫回 run 資料夾）：
   core-009 21 PASS / 8 FAIL、core-010 28 / 6、core-011 29 / 5。也就是 C2 並沒有讓答案更不可靠。
   評審設定沒有改，這只是側面分析；是否放寬評審視窗留給 owner 決定。
3. **invented 下降**（67 → 54，可回答題 40 → 19）：證據更貼近問題後，答案較少靠泛泛的段落延伸。
4. **時間 +17%（相對 C1）**，在 20% 以內；相對基準仍少 55%。

## 決定

涵蓋率高於基準與 C1，時間惡化在 20% 以內，contradicted 持平、invented 下降，**保留 C2**。
退回方式：把 1.10.0 從 `disabled/` 移回、移出 1.12.0，revert `43dcd76`，重啟 Agent Web。
