## 4. 解讀

1. **多輪檢索在正式環境有效。** 交給合成模型的參考來源從 22% 到 41%，答案實際引用的從 17% 到 26%。
2. **答案涵蓋率幾乎沒動（0.28 → 0.30，在浮動範圍內）。** 瓶頸已從檢索移到合成：
   模型拿到更多對的頁面，但答案只寫其中一部分，加上 1.8.0 的保守指引，參考答案的重點仍多數沒寫到。
3. **可答題的根據變得更紮實。** 矛盾題 7 → 4、延伸項目 50 → 35。
4. **代價是時間。** 可答題耗時中位數 137 → 200 秒（約 +60 秒），每題多約 4 次模型呼叫。
5. 每版只跑一次；單題升降（例如 Q1021 0.38 → 0.56、Q1071 0.25 → 0）不能當結論。

## 5. 選項（owner 決定）

1. **保留 1.9.0**：根據更紮實、引用更多對的來源，接受約 +60 秒。
2. **回到 1.8.0**：較快，涵蓋率相同。
3. **繼續往合成下手**：例如讓答案依參考的面向逐一回答、或提高合成可用的段落與輸出長度；這針對第 4.2 點，
   但要小心延伸再度增加。
