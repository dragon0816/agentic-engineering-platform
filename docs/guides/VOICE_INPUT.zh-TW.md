# 用說的代替打字（Telegram 語音訊息與 Agent Web 麥克風）

給想用語音操作 AEP 的人，以及要在自己電腦上開啟語音功能的 owner。設計見 `docs/phases/VOICE_INPUT.md`，
契約見 `docs/CONTRACTS.md`「Voice input」。

## 1. 它做什麼、不做什麼

- 你說的話在**這台電腦上**轉成文字（faster-whisper，本機模型），**不會送到雲端**。
- 轉出來的文字會先給你看，之後就和你**打同樣的字完全一樣**：問問題、跑 Workflow、改程式，都走原本的
  路徑、原本的確認與核准。語音不會多一個確認步驟，也不會少任何一個。
- **只保留文字，不保留錄音**。錄音只在記憶體裡轉完就丟掉（轉失敗也一樣）；文字紀錄保留天數和「任務結果
  摘要」相同（預設 30 天，在「記憶」頁設定）。
- 每段語音最長 **3 分鐘**、最大 **10 MB**。
- 看起來含有密碼、token 的語音，和打字一樣會被拒絕：「That message was not forwarded: it looks like it
  contains a credential.」，內容不顯示也不保存。

## 2. 在 Telegram 用語音

1. 對 AEP 的 bot 按住麥克風錄一段**語音訊息**（或傳一個 3 分鐘以內的音訊檔）。
2. bot 先顯示「🎤 轉文字中…」，接著變成「🎤 你說：「…」」，讓你確認它聽到什麼。
3. 之後的回答、問題、表單卡片、核准按鈕都和打字一樣。
4. 語音訊息附有說明文字（caption）時，說明文字放在前面，再接轉出的文字。

**卡片上的確認一定要按按鈕。** 出現「確認執行」／「修改」的卡片時：

- 說「好」「確認」「執行」**不會**執行，bot 會回「請按「確認執行」按鈕確認，語音不能代替確認。」，卡片保持開著。
- 說「取消」會取消，說「修改」會進入修改，和打字一樣。

錄影訊息（圓形影片）不支援，請用語音訊息。

## 3. 在 Agent Web 用麥克風

1. 輸入框下方有 **🎤**（只有這台電腦開啟語音時才會出現）。第一次使用時，瀏覽器會問是否允許麥克風，請允許。
2. 按 🎤 開始錄音，旁邊會顯示「錄音中 0:05 / 3:00」；再按一次（■）停止。到 3 分鐘會自動停止。
3. 轉好的文字會放進輸入框，並顯示「語音轉文字，請確認內容後送出。」。**這時什麼都還沒送出。**
4. 看一下、需要的話修改，再按 **Send**。送出的內容永遠是輸入框裡的文字。

表單或卡片開著時，用語音送出「好」不會確認，請按表單上的按鈕。麥克風被拒絕或轉文字失敗時，會在 🎤 旁邊
顯示原因，輸入框裡原本的文字不會被動到。

## 4. Owner：在這台電腦開啟語音

語音預設關閉。開啟需要三件事：套件、模型、`host.json`。

1. **安裝語音套件**（owner 已核准：faster-whisper、PyAV、OpenCC）：
   `python -m pip install "agentic-engineering-platform[voice]"`（在 AEP 的 Python 環境中；開發環境用
   `pip install -e ".[voice]"`）。
2. **放好模型**：AEP **不會自己下載模型**。把核准的 faster-whisper 模型資料夾（預設 Whisper small int8，
   CTranslate2 格式：`model.bin`、`config.json`、`tokenizer.json`、`vocabulary.*`）放到這台電腦，例如
   `C:\aep\models\whisper-small`。
3. **算出模型的 hash**：
   `python -m voice.whisper C:\aep\models\whisper-small`
   印出的 64 個字元就是要寫進 `model_sha256` 的值。之後模型資料夾只要有任何檔案變動，語音就會停用
   （回覆「語音轉文字目前無法使用（模型未安裝）」），需要重算。
4. **寫進 `host.json`**：

   ```json
   "voice": {
     "enabled": true,
     "model_path": "C:\\aep\\models\\whisper-small",
     "model_sha256": "<上一步印出的 hash>",
     "hints": ["CMX500", "Wi-Fi 8"]
   }
   ```

   `hints` 是常講的產品名稱，幫助辨識拼法；可以不寫。其他可調整的值（上限、逾時、語言）見
   `docs/CONTRACTS.md`「Voice input」。
5. **重新啟動 Agent Web**（先確認沒有進行中的工作：`/api/tasks`、Telegram 的問答）。之後 Telegram 與
   Agent Web 共用同一個模型，第一次轉文字時才載入，閒置 10 分鐘後釋放記憶體。

關閉語音：把 `enabled` 改成 `false` 或拿掉整段 `voice`，重新啟動即可，文字功能完全不受影響。

## 5. 常見訊息

| 你看到 | 原因與處理 |
|---|---|
| 這台電腦沒有開啟語音輸入，請改用文字。 | `host.json` 沒有開啟 `voice`（見第 4 節） |
| 語音超過 3 分鐘，請分段或改用文字。 | 太長；分成幾段 |
| 不支援這種音訊格式… | 請用 Telegram 語音訊息或網頁麥克風 |
| 沒有聽到內容，請再說一次。 | 錄到的是靜音或雜音 |
| 語音轉文字目前無法使用（模型未安裝）… | 模型路徑錯、hash 不符或沒裝語音套件 |
| 語音處理忙碌中，請稍後再試。 | 同時有其他語音在轉；稍等再試 |
| 請按「確認執行」按鈕確認，語音不能代替確認。 | 卡片或表單的確認要按按鈕 |
